## 1. 目的

P25 の歯止め（G1〜G4）は「取り出した値に、発話の中の根拠があるか」を見た。見ていない行で違う値での実行は 6.7% → 4.2% に減ったが、目安の 3% に届かなかった。
残った 10 行は「根拠が無い」ではなく、**発話の中に別の値の根拠があって、片方を取り違えた**型だった（`results/P25_20261009_guard.md` 3 節）。

ここでは、**取り出した値と食い違う根拠が発話にあれば聞き返す**確かめ（2 段目）を足す。考え方は P25 と同じ（外したときは、違う値で実行ではなく聞き返しに倒す。交換は利用者が受け入れた）。学習なし・端末なし。既存のソースは変えず、`p25_arguments` の上に重ねる。

## 3. 歯止めの 2 段目（`app/p26_arguments.py`）

1 段目（`p25_arguments`）が通した値だけを見る。止めたときは「引数が足りない」（`missing = ["value_check"]`）として返す。見る文は発話そのもの（漢数字だけそろえる）。

|歯止め|中身|止める例（直す用の行から）|
|---|---|---|
|G5 止める語と値の食い違い（空調）|空調の語のすぐ後に止める語があるのに、値がその対象のまま（冷房を切る → cool・エアコンを消す → auto・風を止める → 風量が 0 でない）。値が「止める」なのに、打ち消した止める語（切らずに・止めないで）がある|冷房を切りたいな → cool／エアコンは切らずに風だけ止めて → off|
|G6 止める語と再生の食い違い（メディア）|値が「再生」なのに、止める語（止めて・ストップ・一時停止）がある。打ち消しと「止めた曲を続きから」は除く|電話をかけるので曲を止めておいて → 再生|
|G7 程度の語と値の食い違い|値の語（音量・風量・温度）のすぐ後に最大・最小・いっぱい・ゼロ・一番 などがあるのに、値が 1 段だけ動いた。「半分」なのに値がいまの値の半分でない。「N度半」なのに値が N.5 でない|音量をいっぱいまで上げて → 14／今の半分に下げて → 10／二十四度半 → 24|
|G8 ひらがなの数|ひとつ・ふたつ・みっつ … があるのに、値といまの値の差がその数でない|風量をふたつ上げて → 4|
|G9 別の場所への移動の語（ナビ）|目的地の設定（経由地の追加は除く）で、目的地のほかに、場所の語 ＋ に・へ・まで ＋ 移動の語（寄る・向かう・行く・着く・戻る）がある。「A に寄ってから B」と、目的の語（修理に行く など）は除く|駅に着く前に花屋に寄って → 目的地 花屋／トイレに行きたいからサービスエリアに寄って → 目的地 トイレ|
|G10 入れる指定と値の食い違い（空調）|暖房・冷房・デフロスターを「入れる・つける」と言っているのに、値に mode が無い|足元が冷えるので暖房をつけて → 温度 26|
