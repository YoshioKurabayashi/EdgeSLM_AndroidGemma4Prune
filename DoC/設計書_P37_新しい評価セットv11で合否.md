# 設計書 P37: 新しい評価セット v11 で合否を測る（P35 の構成・アプリ v2 でも）

版 0.2（2026-10-14・結果まで）

対象のソース: `app/p37_data.py`・`app/p37_verdict.py`・`app/p37_app.py`・`scripts/run_p37.ps1`・`data/challenge_v11/`・`results/P37/preregistration.md`・`results/P37/verdict.md`・`results/P37/app_check.md`

## 1. 目的

P35 の構成（アプリ v2 に入れたものと同じ）が目標を満たすかを、**どの調整にも使っていない新しい評価セット v11** で決める。あわせて、v11 を**端末のアプリ v2 の中だけで**判定させ、PC と同じ判定・同じ KPI になるかを確かめる（スマホだけで合格の数字が出るか）。v6〜v10 は直す用。

## 2. 測る前に決めたこと（`results/P37/preregistration.md`）

- 規則・引数・語の一覧・ヘッド・アプリ v2 の判定の部品の md5 を、v11 を書く前に固定した
- 本命 = ヘッド 1,656 行・P31 の規則・P35 の引数・S1 の seed（層 17 = 17・層 26 = 29）・BERT bert_s0。比べる相手 = P33 の構成／アプリ v1
- 数え方は P33 の改定後（これまでの数え方は参考）。載せる層 26 を主に見る
- 予想（層 26・本命）: EtoE 0.95〜0.98・重大 0.3〜1.2%・不要な聞き返し 3〜5.5%・通常 1.5〜3.5%。アプリ v2 は 600 行 × 2 層すべてで PC と同じ

## 3. 評価セット v11（`app/p37_data.py` → `data/challenge_v11/utterances.jsonl`）

- 行数の形は v8〜v10 と同じ（H 150・K 120・N 180・F 50・G 100）。600 行・md5 `354de4fd40b262130214418a10021817`
- H の問い合わせ 40 = 返さないものを聞く 20（周辺の検索 8・説明書 4・車両の状態 4・曲の情報 4。2 文目は「〜は」の形が多い）＋ 知識など 20
- 対象の行に、止める語と別の操作を 1 文で言う形（暖房を止めて冷房に切り替えて・ラジオを止めて音楽をかけて）・条件を付けて探す依頼・車両の状態と曲の情報の「〜は何」の形を入れた
- 重なりの確かめ（学習と 0.60・これまでの評価セットと 0.70）で約 125 文を、結果を見る前に置き換えた
- 単語の表（`words.tsv`）に v11 を足した（8,728 文）

## 4. 合否の段（`app/p37_verdict.py`。`p34_verdict` を写して評価セット・構成を替えたもの）

encode → device（お試しアプリで h）→ text（BERT）→ judge。judge は v10 のデータに差し替えて動くことだけを確かめた（P35 の当たりと同じ数字）。

## 5. アプリ v2 での確かめ（`app/p37_app.py`）

|段|中身|
|---|---|
|`prep`|PC の判定（v11 の h → ヘッド・S1 の seed → `p36_decide`）と Gemma の ID 列を `eval_v11.jsonl` に書く。画面の設定は P36 のものを写し、確かめ用の行だけ v11 に替える|
|`truth`|PC の BERT の ID 列（v11）|
|`deploy`|`eval_v11.jsonl` と設定をアプリ v2 の置き場へ|
|`check`|アプリ v2 に v11 を層 17・26 で判定させ、PC と 1 行ずつ突き合わせる。**値まで見た KPI も、端末の判定の引数を正解の引数と比べて出す** → `results/P37/app_check.md`|

## 7. 結果（`results/P37_20261014_verdict.md`）

**層 26・本命は通常の誤りだけ目標の外で不合格**: 値まで見た EtoE 0.950・重大な誤り 0.67%・不要な聞き返し 4.0%・通常の誤り 4.3%（層 17 は聞き返し 5.1%・通常 4.2%）。予想（通常 1.5〜3.5%）の外。比べる相手（P33 4.7%・アプリ v1 7.2%）よりは良い。

- 通常の誤り 26 行: ヘッドの読み出しの機能の取り違え 10（＋取り違えて断った 2）・語が足りず対象を断った 6（3.4%）・返さないものを聞く依頼の取りこぼし 3・雑談と意図が不明 5
- **アプリ v2 の中だけで出した判定は、600 行 × 層 17・26 のすべてで PC と同じ**。値まで見た KPI も同じ（1 回の判定の中央値 144・173 ms）
