## 1. 何をするシステムか

車内での 1 回の発話（文字）を受け取り、次の 4 つのどれかに振り分ける。

|結果|中身|
|---|---|
|実行|8 つの機能のどれかを、引数つきで呼ぶ|
|雑談|会話として受ける（機能は呼ばない）|
|聞き返す|実行してよいか決めきれないとき。利用者に確かめる|
|断る|車に無い機能を頼まれたとき（「冷蔵庫は使えません」）|

機能は 8 つ（EdgeSLM_MultiHead_Multi の `configs/tools.json`）。

|種類|機能|誤って実行したとき|
|---|---|---|
|操作系（車の状態を変える）|空調 `control_hvac`・メディア `control_media`・ナビ `set_navigation`|**重大な誤り**|
|読むだけ|車両の状態 `get_vehicle_status`・説明書 `search_vehicle_manual`・周辺の検索 `search_poi`・曲の情報 `get_media_info`・カメラ `capture_camera`|通常の誤り|

考え方は「**3 つがそろったときだけ実行する**」: BERT が対象と判定・LM ヘッドの確信度が高い・引数が取り出せる。どれか欠けたら聞き返す。精度を 1 つの部品に求めない。

## 2. 全体の流れ

```
発話（文字）
 │
 ├─① BERT（文だけを読む 2 値）──── 確率が断る閾値以上 ───────────────→ 断る
 │        確率はあとで使う（⑦）
 │
 ├─② Gemma 4 E2B の前半 26 層（NPU・64 トークンまとめ読み）→ h（最後の位置・平均）
 │
 ├─③ LM ヘッド（小さな MLP）→ 行き先 9 クラスの確率・棄却の得点
 │
 ├─④ 規則（決定的）────────── どれかに当たる ───────────────────→ 聞き返す
 ├─⑤ 棄却の得点 ≥ 閾値 ─────────────────────────────────────→ 聞き返す
 ├─⑥ 行き先の確率 < 確信度の閾値 ───────────────────────────────→ 聞き返す
 │
 │   行き先が雑談 ──（BERT の確率 ≥ 0.5 なら聞き返す）──────────────→ 雑談
 │
 ├─⑦ 引数を取り出す（決定的）── 足りない ───────────────────────→ 聞き返す
 │   検査（schema・値の範囲・ポリシー）── 違反 ───────────────────→ 断る／聞き返す
 │   BERT の確率 ≥ 0.5（フラグ）────────────────────────────→ 聞き返す
 │
 └─────────────────────────────────────────────────→ 実行（機能＋引数）
```

順番は EdgeSLM_MultiHead_Multi の `Dispatcher._handle` と同じ。

### 3.2 引数の取り出し（LLM は使わない。キーワードと正規表現の決定的なコード）

順番: **`p23_arguments`（整える）→ `p22_arguments`（主節を先に見る）→ 決まらなければ、これまでの処理**（EdgeSLM_MultiHead_Multi の `arguments.resolve` → `p9` → `p17` → `p21`）。そのうえで **`p25_arguments`（歯止め 1 段目）**が、そろった値に発話の中の根拠があるかを確かめ、無ければ聞き返す。さらに **`p26_arguments`（2 段目）**が、値と食い違う根拠が発話にあれば聞き返す（P25・P26。**検証用の構成。アプリにはまだ入れていない**）。

|層|何をするか|例|
|---|---|---|
|`p23_arguments`|発話を整える: 接続の語（んで・ため・し・ければ）の後ろで区切る／打ち消しの前を落とす（A じゃなくて B）／後ろに足した理由を落とす／漢数字をそろえる。空調で温度と風量を 1 文で言うとき、分けて取り出す|止めるんじゃなくて音を下げて → 音量を下げる（元は一時停止）|
|`p25_arguments`（歯止め）|G1 既定値（auto・再生）で実行するときは、それを支える語（つける・入れる／かける・流す など）が要る／G2 発話の数字は、取り出した値で説明できる（値そのものか、いまの値との差）／G3 空調で止める操作と入れる・強弱の操作を両方言ったら聞き返す／G4 目的地に副詞・述語の切れ端が入ったら聞き返す|冷房きって → 聞き返す（元は auto）／温度は24度、風量は2にして → 聞き返す（元は風量だけ）|
|`p26_arguments`（歯止め 2 段目）|G5 止める語があるのに値がその対象のまま／G6 止める語があるのに再生／G7 最大・半分・N度半 なのに 1 段だけ・N のまま／G8 ひらがなの数と値の差が合わない／G9 目的地のほかに別の場所への移動の語／G10 暖房をつけて なのに mode が無い|冷房を切りたいな → 聞き返す（元は cool）／駅に着く前に花屋に寄って → 聞き返す（元は目的地 花屋）|
