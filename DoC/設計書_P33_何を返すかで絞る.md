# 設計書 P33: 機能が「何を返すか」で絞る・引数の直し・数え方の改定

版 0.2（2026-10-13・当たりまで。「〜は何」の形を足した。合否は v10 で測る）

対象のソース: `app/p33_scope.py`・`app/p33_arguments.py`・`app/p33_check.py`・`results/P33/check.md`・`results/P33_20261013_returns.md`

## 1. 目的

P32（v9）で本命が通常の誤りだけ目標に届かなかった原因を直す。

- 対象と同じ語（店・駐車場・車検）で、機能が返さないもの（値段・在庫・メニュー・費用）を聞く依頼が、周辺の検索・説明書で実行された（v9・層 26 で 12 行）
- 値まで見た重大な誤り 2 行（「シャッ**フル**」で音量最大・「行く途中にコンビニ」を経由地）

## 2. 利用者の決定（2026-10-13）

|決定|中身|
|---|---|
|周辺の検索が返すもの|**施設の名前・場所・距離・営業時間**|
|説明書が返すもの|**操作方法・仕様・意味**（費用や在庫は返さない）|
|知識・いまの値を聞く依頼（日経平均・富士山の高さ）|**雑談でよい**|

数え方の改定: 機能にない依頼を雑談として受けたら**正解**に数える（これまでは通常の誤り）。ツールは実行していない。この改定は v10 から使う。P32（v9）の合否は記録どおり（結果を見てから基準を動かさない）。参考に、改定後の数え方で v9 を数え直すと、P31 の本命（層 26）の通常の誤りは 3.8% → 2.8%。

## 3. 何を返すかで絞る（`p33_scope`）

P31 の語の一覧は「**何についての依頼か**」を見ていた。ここでは「**何を聞いているか**」を取り出し、返せるものの**閉じた一覧**で説明がつくかを見る。開いた外側（値段・在庫・メニュー…）は列挙しない。

|取り出し方|例|聞いているもの|判断|
|---|---|---|---|
|〜を／は／が／って ＋ 教えて・調べて・探して など|近くのガソリンの**値段**を教えて|値段|返さない → 断る|
|名詞 ＋ 教えて（助詞なし）|最寄りの**スタンド**教えて|スタンド|施設 → 通す|
|〜か ＋ 教えて・調べて（周辺の検索だけ）|この店に**牛乳**があるか調べて|「ある」の主語|施設でない → 断る|
|〜か ＋ 教えて（「ある」以外）|このカフェにペットを連れて**入れる**か|入れる|営業時間（開いて・やって）以外 → 断る|
|「いくら」|車検にいくらかかるか教えて|お金の額|どちらの機能も返さない → 断る|
|頼む動詞が無い「〜は（何・いくつ・いつ…）」（版 0.2 で足した）|この駐車場の**料金**は|料金|返さない → 断る。「〜はどこ」は場所・部品の位置を聞いているので通す|

- 返せるもの: 周辺の検索 = P31 の施設の語 ＋ ところ・場所・名前・住所・距離・営業時間・何時 など（`POI_RET`）。説明書 = P31 の車の部品の語 ＋ 方法・手順・意味・容量・規格・時期・目安 など（`MANUAL_RET`）
- 聞いているものは、目的語の直前の「名詞らしい語の並び」（単語の表 `words.tsv` で分けた語。「の」で切る）。「ガソリン の 値段」→ 値段
- **探す条件を付けて施設を探す依頼は通す**（安い・24 時間・〜してくれる店・犬と泊まれる宿）。返すのは施設の名前・場所なので、返すものの定義に合う。学習の対象の行（最安のスタンド・鍵を作ってくれる店）と同じ扱い
- 取り出せないとき（「近くにコンビニある」など）は P31 のまま

**見ていない対象の言い方を断る割合**: 学習 1,656 行の対象の行だけを見て書いた時点で、v1〜v9 の対象の行で断ったのは、周辺の検索 284 行中 5（1.8%）・説明書 338 行中 7（2.1%）。この 12 行を見て施設・仕様の言い方（ショップ・歯医者・交番・トルク・粘度・仕組み・処置・場面）を足した。残りは打ち間違い 1 行（駐車上）。

版 0.2 で「〜は（何・いくつ…）」の形を足したとき（v10 を書く前）: 足しただけの時点で、v1〜v9 の説明書の対象の行 461 行中 7 行（1.5%）を断った（スイッチ・金具・席・記号・油種・対応）。「〜はどこ」は場所を聞く形として通し、残りの言い方（油種・対応・記号・スイッチ・席）を足した。

注意（測り方の汚れ）: この仕組みは、v9 の機能にない依頼の行を**見た後**に作った。語の一覧は利用者が決めた仕様（返すもの）から書き、v9 の機能にない依頼の行では語を足していない（機能にない依頼の行は評価にだけ使う決まり）。ただ、仕組みの形そのものは v9 の行を見て思いついたので、v9 での数字は甘い。合否は v10 で。

## 4. 引数の直し（`p33_arguments`）

|直し|中身|v9 の例|
|---|---|---|
|E1 最大・最小の語を単語の切れ目で見る|元の引数の取り出しは「フル」「最高」などを部分一致で見る。最大・最小の語が単語の切れ目に合わない所にしか無ければ、そこを伏せてもう一度取り出す|曲をシャッフルしてください → 音量 40（最大）|
|E2 「途中に」|目的地・経由地が「〜途中に／途中で／ついでに ＋ 名詞」なら後ろの名詞だけ|行く途中にコンビニへ寄っていきたい → 経由地「行く途中にコンビニ」|

確かめ: 引数の他の語の一覧も部分一致を調べた（空調・メディアの対象の行 1,742 行）。値を大きく動かす部分一致は「フル」（シャッフル・6 行）だけだった。
